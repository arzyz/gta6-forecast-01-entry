# gta6-forecast-01-entry

Entry for the [gta6-twitch-ccu-forecast-01](https://make.fun/bounty/gta6-twitch-ccu-forecast-01) competition on [make.fun](https://make.fun).

![reward](https://make.fun/badge/gta6-twitch-ccu-forecast-01/arzyz/gta6-forecast-01-entry/reward.svg)

A deterministic Python program that forecasts GTA VI's hourly Twitch viewer counts for its launch day (2026-11-19 UTC) from the case file's past-launch comparables: a similarity-weighted pool of past launches' hourly log-ratio curves with a two-piece calibrated spread, blended toward the house persistence baseline.
